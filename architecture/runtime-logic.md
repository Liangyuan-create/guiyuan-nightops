# 归元夜航运行逻辑图（v1.3）

> 单次调用（拍/轮）全流程 + 跨轮飞轮 + 自迭代外环。支持 Mermaid 渲染的 Markdown 阅读器可直接显示下图。

```mermaid
flowchart TD
    T["触发：cron / 手动 / 会话"] --> P{"调用参数齐全？<br/>本轮主题+真问题、产出目录"}
    P -->|"缺失"| REFUSE["拒绝运行<br/>不猜测、不代填、不用默认值"]
    P -->|"齐全"| LOCK{"运行锁三态判定（八-B2）"}
    LOCK -->|"空闲 / done≥2分钟"| PHASE0
    LOCK -->|"done<2分钟 / 在跑<25分钟"| SKIP["跳过本拍（空触发，不写台账）"]
    LOCK -->|"锁污染且≥25分钟"| TAKEOVER["异常接管：覆写开跑+登记"] --> PHASE0

    PHASE0["阶段0 装载定位卡<br/>读 skill → B版 → 目标卡 → 上轮进展日志<br/>写 状态.md（定位卡+本轮验证点）"]

    subgraph LOOP["阶段1..N：验证点循环（B版 Phase2 四阶 + 六控制器）"]
        direction TB
        EXEC["执行与取证（五级标注+来源日期）"] --> FOUR["四阶：对峙 → 前提发散 → 整体归元 → 留白"]
        FOUR --> CTRL{"六控制器检查"}
        CTRL -->|"关键变量缺失"| SUSPEND["挂起：标证据不足→虚白清单<br/>跳下一子问题（禁止带缺口硬收敛/整轮空等）"] --> REWRITE
        CTRL -->|"连续3轮无实质进展"| FUSE["熔断五步复位<br/>暂停→接受新定位→盘点→重设60分→重启"] --> EXEC
        CTRL -->|"正常推进"| REWRITE["重写 状态.md（八-A 全文替换）"] --> EXEC
    end

    CTRL -->|"收敛（连续2轮无新增实质维度）<br/>或 档位上限 / 时间预算耗尽"| BUILD["阶段N+1 交付组装<br/>防火墙七要素 · 全文禁分"]
    BUILD --> OWN{"收尾归属校验（八-B3）"}
    OWN -->|"失配=已被接管"| GHOST["静默退出：放弃全部收尾写"]
    OWN -->|"通过"| FINISH["收尾序列<br/>进展日志追加 → 状态重写 → 教训上升检查<br/>→ 调用台账追加一行 → 锁写 done"]
    FINISH --> VB["虚白清单 = 轮后验收入口"]
    VB --> USER(("用户验收 / 批注"))
    FINISH --> NEXT["下一拍：强制读盘恢复<br/>（状态在磁盘，不在上下文）"]
    USER -->|"批注=最高权重输入"| NEXT
    NEXT -.->|"同一飞轮连续运转"| T
    FINISH -.->|"回写候选≥3条触发"| SELF["自主自迭代轮（八-D）<br/>证据锚→缺陷→攻击评审→备份→pending冷却"]
    SELF -.->|"修订生效"| T
```

## 读图要点

| 区域 | 对应机制 | 防的失效 |
|---|---|---|
| 入口三闸 | 参数缺失拒跑 / 运行锁三态 | 无目标空跑；多实例互踩 |
| 验证点循环 | B 版四阶+六控制器 | 空转（熔断/封顶）；妥协（挂起不许硬收敛）；假收敛（实质维度判据） |
| 交付组装 | 输出防火墙 | 幻觉数字外流、自评分 |
| 收尾序列 | 归属校验→四步落盘→写 done | 双实例互踩收尾；对下一拍不可见 |
| 外环两条虚线 | 跨轮读盘恢复 + 自迭代协议 | 上下文失真；系统自身退化 |
| 用户节点 | 虚白清单验收+批注回灌 | 无人值守下的方向漂移（人只做验证视角，不做推进闸门） |
