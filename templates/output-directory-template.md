# 产出目录文件组（模板）

> 每个用夜航跑的项目建一个独立产出目录。运行时只写这个目录（状态同步回写 PROJECT.md 除外）。首次调度时把 `目标卡.md` 写好；状态、进展日志、虚白清单、运行锁与交付目录由运行时自动创建维护。

## 目标卡.md（调度时写入，运行时只读）

```markdown
# <项目名> 目标卡

## 理想状态（120：文字描述，不写分数）
<最终想达成的状态，一段大白话>

## 真问题
<表面问题背后的真问题>

## 验证点清单（60：可外部验证的关键结果）
- [ ] VP1：<第一个可验证的实体>——判据：<什么证据算通过>
- [ ] VP2: …
- [ ] VP3: …

## 边界
- 不做：<这一版明确不做的>
```

## 状态.md（每轮全文重写：定位卡+当前位置）

````markdown
# 状态

```
最后重写：<最近一次 date 输出>
当前位置：<阶段/验证点/轮次>
控制器计数：<熔断计数/收敛计数>
待核对验证：<指针或无>
节名清单：# 快照 | # 当前验证点 | # 下一步
```

## 快照
<当前快照>

## 当前验证点
<定位卡四项：已知/资源/限制/外部锚 + 本验证点当前位置>

## 下一步
<下一轮的第一个动作>
````

## 进展日志.md（只追加，跨轮连续性唯一载体）

```markdown
# 进展日志

## <YYYY-MM-DD> <主题>
- 验证点结果：<过/未过+证据>
- 关键发现：<路径与一句话>
- 留给下一轮的钩子：<待办>
```

## 虚白清单.md（轮后验收入口，写给白天的你）

```markdown
# 虚白清单（<日期>轮）

## 验证点状态
- VP1 通过——证据：<文件/测试/数字>
- VP2 未通过——原因：<…>

## 需要你裁决的
- <问题+建议+回退办法>

## 建议的下一个验证点
- <…>

## 最小实验
- 做什么/投入/观察什么/什么结果继续/什么结果停止/明天第一个动作
```

## 运行锁.md（单文件锁，运行时维护）

首行两种合法值：`date` 实测整行（在跑）或 `done`（收尾）。人不需要维护它；异常残留超过 25 分钟会被下一拍自动接管。

## 交付/ 目录

每个验证点一份 `<验证点>-<名称>.md`，按 B 版防火墙七要素组装。

## 调用台账（跨项目，单独放）

见 `SKILL.md` 第九节：一行一次调用，仅追加。建议放跨项目知识库根下，不放任何单项目产出目录内。
