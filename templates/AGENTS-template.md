# <你的项目名> 工作规则（AGENTS 模板）

> 用法：把本文件改名为 `AGENTS.md` 放在你项目的根目录。支持自动加载项目级 AGENTS.md 的 agent 工具（ZCode / Claude Code 等）会在每个会话自动读到它——这是无人值守会话唯一保证被加载的路由锚。把尖括号内容替换成你自己的信息后删除本行。

## 文件地图

| 文件 | 角色 |
|---|---|
| `PROJECT.md` | 项目状态单一入口，任何任务前先读 |
| `guiyuan-nightops` skill | 长程任务唯一流程权威（本仓库 `SKILL.md` + `kernel/workflow-b-v1.3.md`） |
| `<你的产出目录>` | 所有交付物唯一去处 |
| `<你的其他协作流程文档>` | 仅适用于有人在场协作的任务 |

## 流程路由

**长程自主任务**的识别条件（满足其一）：cron 定时触发；用户说"跑今晚的任务""开始夜航""继续夜航""开始飞轮""无人值守迭代"及同义表述。

长程任务执行顺序：

1. 读 `PROJECT.md` 恢复状态；
2. 加载 `guiyuan-nightops` skill，全程按 skill 执行；
3. 不向用户提问，卡住走 skill 的熔断与挂起。

**其他任务**（有人协作的开发、讨论、修改配置）：按你自己的协作协议分级执行。

## 红线（自主运行与有人协作时都生效）

- skill 必需参数（本轮主题+真问题、产出目录）缺失时拒绝运行，不猜测、不代填、不用默认值顶替。
- 自主产出只写产出目录；你声明的只读敏感区（如个人档案）只读。
- 不自评任何分值、百分比、进度数；交付物全文禁分，验收权归用户。
- 执行内核（`kernel/workflow-b-v1.3.md`）只读引用，不修改；对运行时层的改动只落在你的项目目录。
- 不花钱、不对外发送、不订外部服务；不动系统其他区域。
